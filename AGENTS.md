# Instrucciones para agentes

Para instalar o reconstruir GeoPadrones desde un clon sin modelos ni datos, lea primero [Setup/README.md](Setup/README.md) y [Setup/FUENTES_Y_LIMITES.md](Setup/FUENTES_Y_LIMITES.md). Contienen los comandos, las fuentes originales, las revisiones fijadas, la configuración CPU/GPU y los límites de reproducibilidad.

No incluya credenciales, pesos, datos catastrales ni volúmenes operativos al publicar. Respete los cambios existentes y no borre datos del usuario para reconstruir o probar la aplicación. No presente métricas publicadas en otros países como precisión medida en Lavalleja.
